- modular Python architecture

### 📊 Process Quality KPI Reporting Automation

A production-inspired reporting workflow that extracts completed operational tasks from a simulated centralised system, applies team and SLA business rules, and updates an Excel workbook used for weekly KPI reporting.

The workflow is designed to run automatically every Monday at **12:00 PM Europe/Dublin time** through a notebook platform’s built-in scheduler.

**Key functionality:**

- SQL extraction from a SQLite database
- dynamic two-week reporting periods
- exclusion of the current incomplete week
- task-tag and agent-based team validation
- task-type classification
- SLA performance classification
- Pandas data preparation
- automated team-tab updates
- preservation of existing Excel formulas
- week-over-week KPI reporting
- team-level performance comparison
- scheduled notebook execution

**Technologies:** Python, SQL, SQLite, Pandas, OpenPyXL, Excel, Git, GitHub

[View the repository](https://github.com/DiditaDeliaAndreea/operations-kpi-reporting-automation)
